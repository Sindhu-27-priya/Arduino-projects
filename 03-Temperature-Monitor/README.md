# 03 - Temperature Monitor

A basic Arduino-based temperature monitoring project using a temperature sensor to measure ambient temperature and display/output readings.

## 🔗 Live Simulation
You can run and test this project directly in your browser without hardware:
* **[Wokwi Interactive Simulation](https://wokwi.com/projects/472404113634182145)**

## 🛠️ Components Used
* **Arduino UNO** (or compatible board)
* **Temperature Sensor** (e.g., NTC Thermistor / LM35 / DHT11)
* **Resistors & Jumper Wires**
* **Breadboard**

## 📐 Circuit & Pinout
* **VCC:** Connected to 5V on Arduino
* **GND:** Connected to GND on Arduino
* **Data / Analog Out:** Connected to Analog Pin `A0`

## 🚀 How to Run
1. Open the [Wokwi Simulation Link](https://wokwi.com/projects/472404113634182145).
2. Click the **Play** button to start the simulation.
3. Interact with the temperature sensor in Wokwi to change the simulated values.
4. Open the **Serial Monitor** at 9600 baud rate to view real-time temperature logs.
