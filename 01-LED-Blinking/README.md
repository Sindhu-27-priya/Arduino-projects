# LED Blinking

This is my first Arduino project built and simulated using Wokwi.

⚡ **[Live Wokwi Simulation](https://wokwi.com/projects/472388006774214657)**

## Components
- Arduino UNO
- LED
- 220Ω Resistor
- Jumper Wires

## Working
The LED turns ON for 1 second and OFF for 1 second repeatedly.
